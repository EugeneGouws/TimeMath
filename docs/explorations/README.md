# docs/explorations/

Analytical deep-dives done in chat (desktop + phone sessions) to check whether
an idea is sound **before** it earns a place in PLAN.md or code.

**Everything in this folder is EXPLORED, NOT IMPLEMENTED.** Numbers here came
from throwaway scripts against real data; they validate direction, not
behaviour. When a finding is implemented and tested, promote the durable fact
to CLAUDE.md and note it here.

|File|Question answered|
|-|-|
|`bounds-ladder.md`|How few teachers can staff a year, and which bound binds?|
|`phase3-feasibility.md`|Is the column+student CP-SAT model sound and fast?|
|`phase4-teacher-min.md`|What does minimising distinct teachers cost?|
|`repair-model.md`|What to do when an instance is infeasible?|
|`warm-start.md`|Can last year's timetable seed this year's solve? (No.)|
